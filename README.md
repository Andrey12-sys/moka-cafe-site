# MØKA — сайт-визитка кофейни ☕

Современный одностраничный сайт-визитка для вымышленной кофейни **MØKA**. Дизайн адаптирован для компьютеров, планшетов и телефонов. В проекте **нет фреймворков и сборки**: только HTML, CSS и JavaScript.

## Что умеет сайт

- Адаптивное меню для мобильных устройств.
- Анимированный первый экран, бегущая строка и плавное появление блоков.
- Интерактивная фильтрация меню по категориям.
- Добавление и удаление напитков из избранного; сохраняется в браузере.
- Переключение светлой и тёмной темы; выбор сохраняется в браузере.
- Индикатор прокрутки и удобные ссылки на разделы.
- Поддержка клавиатуры, подписей для кнопок и настройки уменьшенной анимации.
- **Собственные локальные SVG-иллюстрации** — изображения не зависят от внешних фотохостингов.

## Запуск

Откройте `index.html` в любом современном браузере. Можно также запустить локальный веб-сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`.

## Публикация на GitHub Pages

1. Создайте новый **публичный** репозиторий на GitHub.
2. Загрузите все файлы и папку `assets` **в корень** репозитория.
3. Откройте `Settings → Pages`.
4. Выберите `Deploy from a branch`, ветку `main` и папку `/(root)`.
5. Сохраните настройки и дождитесь публикации.

Обычный адрес проекта после публикации: `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

> Это демонстрационный дизайн-концепт. Реальные контакты, цены и местоположение заведения не указаны специально.

## Технологии

`HTML5` · `CSS3` · `JavaScript (ES6+)` · `SVG`

Шрифты: системные Georgia и Arial, с дополнительной загрузкой Google Fonts при наличии интернета (не обязательна). Все иллюстрации проекта созданы специально для этого сайта.
